—— 架构核心变化：手机替代 ESP32 裸板，GT1005 直连手机 BLE，微雪圆屏做移动展示终端 ——

一、架构总览
1.1 核心设计思路
本 Demo 采用「手机 + GT1005 + 微雪圆屏」三件套极简架构，替代此前「ESP32 裸板 + GPS 模块 + GT1005 + 微雪圆屏」的多板方案。核心变化：
• 手机（Android/iOS）替代 ESP32 裸板：自带 GPS（3-5m）、加速度计、陀螺仪、4G/5G、App 算力、Wi-Fi/BLE，一机顶多板
• GT1005 通过 BLE 5.0 直连手机：手机 App 通过蓝牙读取 GT1005 的卫星通信状态、GNSS 位置，通过 SDK 发送 SOS/心跳/离线消息
• 微雪 ESP32-S3-Touch-AMOLED-1.75C 刷小智 AI 固件：做移动展示终端，负责轨迹可视化 + AI 语音对话，Wi-Fi 连云端拉数据
• 云端平台：时空道宇卫星平台 + 自建轻量服务（轨迹存储、电子围栏、AI 问答后端）

1.3 数据流架构（全链路）
有网场景（城市/4G 覆盖区）
手机 GPS 定位 → 手机 App 采集位置/状态 → 4G/5G 直传云端平台 → 微雪圆屏 Wi-Fi 拉取数据 → 屏幕显示轨迹 + AI 语音对话
GT1005 此场景下待命（BLE 保持连接，但不主动发星，省电）。
无网场景（野外/停车场/信号盲区）
手机 GPS 定位 → 手机 App 通过 BLE 读取 GT1005 GNSS 位置（2.5m CEP）→ 手机 App 调用 SDK sendMsgMCQ/SendMsgSFQ → GT1005 经 VHF 卫星链路上报时空道宇平台 → 平台下行到微雪圆屏/车主手机
手机 4G 断开后，GT1005 的卫星链路是唯一通道。SOS 触发时手机 App 立即调 MCQ 发紧急包（含经纬度 + 车主 ID + 事件类型）。

4.2 在 Demo 中的角色
• 刷小智 AI 固件后，自带语音对话能力（「你好小智」唤醒）
• 屏幕显示：宠物/车辆轨迹地图、当前位置、电子围栏状态、卫星链路状态（对星中/待机）
• AI 语音问答：「我的车在哪？」「它今天走了多少公里？」「开启哨兵模式」
• Wi-Fi 连云端拉数据，不经过 GT1005 卫星链路（展示端用 4G/Wi-Fi，省卫星流量）
• 可随身携带，放在展台或挂在身上，Demo 灵活度高
4.3 小智 AI 服务端说明
微雪圆屏默认连接小智官方服务端，支持切换大模型（DeepSeek/Qwen/豆包等）。Demo 阶段用官方服务最快；后期可切吉利私有 AI 后端。
⚠️ 注意：小智 AI 需要 Wi-Fi 联网，微雪圆屏不经过 GT1005 卫星链路。展示端和车载端的通信通道是分离的（展示端走 Wi-Fi/4G，车载端走 4G/卫星）。

5.3 技术实现要点
• Android App（优先）：集成 protocollibrary + ephemerislibrary 两个 AAR，BLE 传输层实现 ModuleOperation 接口
• iOS App（可选）：SDK 为 Android AAR，iOS 需走 GT1005 的 BLE 透传 + 自研协议解析（工作量较大，Demo 阶段 iOS 可用「BLE 抓包 + 网页端」替代）
• BLE 协议文档：需向时空道宇确认 GT1005 BLE 服务/特征 UUID、数据帧格式、分包规则（参考代码 CommunicationManager.java 已有 BLE 实现示例）
• 云端服务：轻量 Node.js/Python 服务，接收 4G 上报数据 + 卫星下行数据，提供 REST API 给微雪圆屏拉取

6.2 Demo 阶段简化方案
Demo 阶段不必自建完整平台，可简化为：
• 时空道宇测试平台：GT1005 卫星上行/下行直接走时空道宇测试环境（需申请测试卡 + 测试账号）
• 轻量自建服务（1 台云服务器即可）：接收手机 4G 上报 + 转发给微雪圆屏 + 存轨迹 + 简单围栏判断
• 小智 AI 官方服务：微雪圆屏语音对话直接走小智官方云，Demo 阶段不自建 AI 后端
• SOS 告警：Demo 阶段简化为「微雪圆屏屏幕弹出告警 + 语音播报」，不做短信/电话外呼

附录 B：GT1005 SDK 快速接入 4 步
1. 集成 AAR：protocollibrary_1.0.0.aar + ephemerislibrary-release.aar 放 app/libs/，加 AAR 依赖 + RxJava3。
2. 传输层桥接：实现 ModuleOperation 接口。BLE 方案：send() = BleManager.sendData()，receive() = BLE 回调。
3. 初始化 + 启动：new DispatchManager(moduleOperation)，BLE 连接成功后调 dispatchManager.start()。
4. 设置监听 + 调用业务 API：通过 ModuleDataManager 设置 6 类监听 + 调用 5 类任务（MCQ/SFQ/TPI/MCI/GMO）。
