来源：D16.5 草案 v2（黑身子奶油脸）经 owner 四轮反馈反转配色定稿：
「这也不像个羊哇」→「铃铛在头上不对、脸再黑一点」→「改成身体白的、脸是黑的」→
「耳朵和四肢在黑色背景下不太明显」→（袜腿 + 浅灰蓝收口）→ **「行吧，先这样」**。

**不参照小羊肖恩的脸部画法、发型分块、配色和表情库**；要照那个画得先有授权。

## 1. 角色：小墨（Xiǎomò）· v4 定稿

| 项 | 定死 |
|---|---|
| 剪影 | 站立小羊：**圆绒球身子**（宽高几乎相等，概念图 v4 核对过——不是竖弹头），边缘叠毛球有起伏；头顶正中一小撮**炭黑呆毛**（上沿浅灰蓝收口）；两只**炭黑长耳下垂**贴在头侧（2.6×4.4 竖椭圆，外摆 0.15rad，纯 `#10151E` 填充），外沿 1px `#1B2330` 压深收口——AMOLED 纯黑屏上黑件不被吃掉；**待机没有外露手臂**（手收进绒毛轮廓，举手的姿势只在听/想/说话状态出现） |
| 脸 | **炭黑大脸板**占上半身（v2 反转）：`#1B2330` 主体、`#10151E` 阴影、`#262F40` 微亮；脸上缘是**米色绒毛扇贝边**（绒帽开口压进脸，不是黑刘海）；两只**米色圆豆眼** `#EFE6D0` + 白高光、位置高且分得开；嘴米色 `#D8C9AC`；腮红两枚照旧 `#FF8FA3` 档 |
| 链路指示 | **胸前小铃铛**：铃身固定金 `#FFC94A`，**铃舌和底沿吃当前状态 accent**——它就是这块屏的链路灯；1px 挂绳，随 bob ±1px 摆 |
| 脚 | **袜腿**：米色袜筒 `#EAE2CA/#D3C9AE`、浅灰蓝蹄沿 1px、炭黑蹄——黑蹄靠沿读出来 |
| 身体绒色 | 米色四档 `#B3A98F / #D3C9AE / #EAE2CA / #FBF5E6`（dark→high），左上光源；场景换装时绒色往场景色混、脸不动（现机制沿用） |
| 性格 | 温吞、慢半拍、认窝。happy = 眼睛弯 ^^ + 铃铛晃 1px |

## 2. 色板（屏侧 muse_pixel.c 已按此实现）

| 语义（C 枚举） | hex | 说明 |
|---|---|---|
| C_BD/BM/BL/BH | `#B3A98F` `#D3C9AE` `#EAE2CA` `#FBF5E6` | 白绒四档 |
| C_SKIND/SKIN/SKINL | `#10151E` `#1B2330` `#262F40` | 炭黑脸/耳/呆毛/蹄共用这套 |
| C_EDGE | `#8A93A6` | 黑件收口：耳沿、蹄沿、呆毛上沿（v4 新增） |
| C_IRIS | `#EFE6D0` | 米色豆眼（含闭眼弧、X 眼） |
| C_MOUTH | `#D8C9AC` | 米色嘴 |
| C_BLUSH/BLUSHD | `#F4AAA0` `#EA8F8E` | 腮红照旧 |
| C_BELL / C_CORD | `#FFC94A` / `#3A2B22` | 铃身金、挂绳；铃舌/底沿 = C_ACC（状态色） |
| C_OUT/C_OUT2 | `#3A2B22` / `#8C8268` | 白绒剪影描边（黑底上弱描边即可）|
| accent×4 / glow×2 / sparkle / rim / shadow / heart | 整张沿用 | 状态色表**不因换角色改** |

## 3. 动画与状态钩子（全部现成机制，换皮不换件）

- 眨眼 / 呼吸起伏 / 2px 跳 / 视线：沿用现有通道。
- 口型：SPEAKING 嘴图章三态 + 铃铛随 bob 轻摆。
- 换装/场景环（D16.2「娱乐都保留」）：正装/车载/亲子道具画在新剪影上，
  铃铛压在装扮最外层（它是本体不是装扮）。
