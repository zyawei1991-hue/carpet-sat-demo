## 1. 角色：小墨（Xiǎomò）· 备选名 owner 另起

| 项 | 定死 |
|---|---|
| 剪影 | 站立小羊：**云朵状羊毛身体**（超椭圆 `18×20` 外沿叠 7 团 r≈7 的毛球，边缘必须有起伏，光滑椭圆会和市面上所有绵羊玩具撞）；头顶一撮**奶油色呆毛球** r=6；两只**下垂耳** 6×3.5 椭圆、±40° 贴在脸两侧；两条 2px 细黑腿。呆毛 + 毛球边 + 垂耳，是 4px 精度下仍唯一的三件套 |
| 脸 | 奶油白圆角椭圆 `12×10` 中心 `(32,26)`；两只圆豆眼 `r=2.1` 圆心 `(27.5 / 36.5, 26)`；嘴 3px 小「w」`(32, 29.5)`；腮红两枚压脸板外 |
| 链路指示 | 「小轨」的天线头换成**胸前小铃铛** `r=2.5` 圆心 `(32, 34)`，带 1px 挂绳；铃铛永远吃**当前状态 accent 色**——它就是这块屏的链路灯，功能映射照旧 |
| 脚 | 蹄底约在 y=56（沿上游排版约束）；腿 `(26.5 / 37.5)`，y 52→56 |
| 尺寸 | 含呆毛 36px 宽 × 50px 高，中心 x=32；跳一下最多 2px（同小轨上限，呆毛不能顶出画布） |
| 性格 | 温吞、慢半拍、认窝。不张嘴大笑；happy 也只是眼睛弯成 ^^ + 铃铛晃 1px |

## 2. 色板（语义命名，≤32 条，两档字库式分深中浅高光）

| 语义 | hex | 说明 |
|---|---|---|
| outline | `#05070A` | 剪影 1px 硬描边 |
| wool dark/mid/light/high | `#14181F` `#232833` `#3A4150` `#5A6B85` | 黑毛在 AMOLED 深底上**靠 high 档边缘光读轮廓**——纯黑会糊进背景，这是黑羊对比度的命门，定稿前必须实屏截图称 |
| face light/mid/dark | `#FFF9EA` `#F2ECDD` `#C9C0AB` | 奶油白脸板，主体受光面 |
| tuft | `#F2ECDD` | 呆毛与脸同档 |
| eye | `#1B2330` | 眼珠；白脸上用近黑不用纯 outline 色 |
| mouth | `#8C7A6B` | 「w」嘴 |
| blush | `#FF8FA3` | 腮红（沿小轨同色，64px 上认得出） |
| bell base | `#FFC94A` | 铃铛固有色，**状态渲染时整体被 accent 覆盖**（链路灯规则） |
| heart | `#FF5C7A` | 心不跟状态色走（同 AVATAR.md 的理由） |
| accent ×4 / glow ×2 / sparkle / shadow / white | 照 `avatar_prompt.md` PER-MODE SCHEMES | 状态色表**整张沿用**，不因换角色改 |

## 3. 动画与状态钩子（全部是屏/App 现成机制，换皮不换件）

- 眨眼 / 呼吸起伏 / 2px 跳：沿用现有 anim 通道。
- 口型：SPEAKING 时嘴图章三态 + 铃铛随播放位置轻摆（`carpet_audio` 的口型翻页钩子现成）。
- 换装/场景环（D16.2「娱乐都保留」）：正装/车载等道具画在新剪影上，道具偏移表要重标一遍，工作量在 App `PixelAvatar.kt` 和屏 `muse_pixel.c` 各自的映射表。
