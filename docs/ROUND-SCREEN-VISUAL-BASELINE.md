# 圆屏视觉对齐基准（v1，2026-11-13）

> 给圆屏侧的视觉对齐材料。App 侧的设计语言全部代码化在
> `apps/android/.../ui/DesignTokens.kt`，本文档把**对圆屏有用的那一部分**摘出来，
> 两侧读同一套数，改了 token 截图就变（谁改谁看得见）。
>
> 自查截图由 `RoundScreenRenderTest` 产出（`apps/android/build/screenshots/round-*.png`），
> 410×502 曲边视口，圆屏侧落手势层时拿同一组图对齐。

## 1. 色板（LVGL 侧照抄这组值）

| Token | 值 | 用途 | 备注 |
|---|---|---|---|
| `Ink.Deep` | `#080B10` | 窗口底 | 屏的待机底色同它 |
| `Ink.Sunk` | `#11161E` | 分组背板 | 只"托"一组行，不当卡片读 |
| `Ink.Card` | `#212834` | 卡底 | 与页面底对比 1.33:1，是"浮起来"的下限 |
| `Ink.Raise` | `#2A3340` | 强调卡底 | 一屏只允许极少数块用 |
| `Ink.Track` | `#364051` | 轨道/进度槽/分隔线 | 不参与语义 |
| `Ink.Outline` | `#455468` | 描边 | **只画强调卡**，普通卡不描边 |
| `Ink.TextHigh` | `#F2F5F9` | 主文字 | |
| `Ink.TextMid` | `#B3BFCE` | 次要文字/值 | |
| `Ink.TextLow` | `#94A1B4` | 说明文字 | 在任何卡底上 ≥4.5:1 |
| `Ink.Ok` | `#3FB950` | 绿=正常 | |
| `Ink.Wait` | `#E3B341` | 黄=等待 | |
| `Ink.Alert` | `#FF6B63` | 红=告警/SOS | 只在真出事时用 |
| `Ink.Sat` | `#58A6FF` | 蓝=卫星链路/动作色 | 唯一动作色 |

两条纪律（两侧通用）：

1. **彩色只表达状态，不做装饰**。红只等于出事，蓝只等于链路/动作；不许给"好看"挑彩色。
2. **语义淡底统一 alpha 0.16**（`Ink.TINT`），不许各处手写透明度。

## 2. 字号阶梯（固件字号映射）

App 侧阶梯是 11 / 12.5 / 15 / 18 / 24 / 34（比值 ≈1.2）。屏侧固件字号 28/22/30 换算过来对齐关系：

| 固件 | 用途 | 对应 App 档 |
|---|---|---|
| 28 | 条目名/标题 | `Type.Title`（18sp）—— 卡片标题档 |
| 22 | 按钮/值/副行 | `Type.Body`（15sp）/`Type.Caption` |
| 30 | 宫格那颗字 | `Type.Hero`（24sp）—— 一屏一个重心 |

规矩：**一屏只允许一个 `Display`/`Hero` 级的大字**（时钟页的大数字算一个）；
数字用等宽字体（秒数 1Hz 刷新用比例字体会抖行）。

## 3. 间距与圆角

| 档 | 值 | 用途 |
|---|---|---|
| 页边距 | 16dp（手机）/ **24dp（圆屏曲边区）** | 内容盒四边各缩 24dp |
| 组间距 | 28dp | 组与组 |
| 卡间距 | 14dp | 卡与卡 |
| 卡内距 | 18dp | 卡内边距 |
| 圆角 | 普通卡 20 / 强调卡 26 / 行内 8 / 胶囊=半高 | **就这四档**，不再多 |

圆屏曲边：关键元素不出 410×502 视口四边 24dp 以内（角部曲率 ~40dp）。

## 4. 触控与反馈

- 可点击区域 ≥56dp（圆屏档；App 手机身是 ≥48dp）。上滑层大按钮 ≥72dp 高（手势规格 §4）。
- 状态变化必须有反馈：loading/空态/错误各有真实文案，不静默。
- 减动效（系统开了"移除动画"）：位移和尺寸归零，**淡入和变色保留**——那是"我按到了"的证据。
- 动效时长档：快 160ms / 常 260ms / 慢 420ms；缓动 emphasized（0.2,0,0,1）；出场比入场快。

## 5. 已定的母题与反模式

- **母题 = 圆**。镜像圆、倒计时环、Avatar 脸全是圆；新元素优先往圆上靠，不要发明第二套形状语言。
- 反模式（taste-skill 的 "AI 味" 清单，两侧都禁）：
  - 紫蓝渐变 + 圆角白卡默认组合
  - 每张卡开头挂一枚 36dp 染色方块图标（23 张真页面 0 张这么干）
  - 混用填充/描边两套图标风格
  - 占位插画、装饰性 emoji
  - 「立即体验」「赋能」这类话术

## 6. 三层底色，一屏封顶

页面底 → 卡底 → 强调卡底，**一屏最多三层**。层级一多就回到"猜哪块是按钮"。
上滑功能层（2-3 个大按钮）、左滑设置（五项封顶）、右滑氛围层都不许出现第四层。

---

改动流程：圆屏侧要改视觉先看这张表；要新增颜色/字号/间距档，先在
`DesignTokens.kt` 里加 token、跑 `ContrastLadderTest`，再同步本文档——不许屏侧单方面引入新值。
