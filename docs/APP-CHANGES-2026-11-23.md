  但收口不能用浅灰蓝，owner 嫌那样耳朵看着发灰；呆毛上沿保留浅灰蓝 `#8A93A6`；
- **脸**：炭黑大脸板占上半身，脸上缘是**米色绒毛扇贝边**（绒帽开口压进脸，不是黑刘海）；

- **比例**：圆绒球身（宽≈高，不是竖弹头）；**待机没有外露手臂**（手收进轮廓，
  举手只在听/想/说话姿势出现）——owner 第一轮就是被"竖身+伸手"打回的；

- **袜腿**：米色袜筒两档 + 浅灰蓝蹄沿 1px + 炭黑蹄；
- 状态色表**不换**（accent/glow/sparkle 沿用 `avatar_prompt.md` PER-MODE SCHEMES）；
- 换装/场景道具（正装/车载）在新剪影上的偏移表重标；铃铛压在装扮最外层。
