# 圆屏四方向交互规格（v1 草案，2026-11-12）

一句话：**Avatar 常驻是唯一的默认态，四个方向各管一件事，点 Avatar 永远兜底。**

圆屏不是小号平板。它的价值在「常显」和「实体化」，所以整套交互围绕一个原则设计：默认态永远是一张有生命的脸，任何功能都是从这张脸出发的一步手势，任何列表都不允许滚超过一屏。

---

## 1. 默认态：Avatar 常驻

- 屏上永远先有 Avatar，呼吸待机；有话要说时它先变脸，再出字。
- Avatar 的情绪即当前状态：普通呼吸=一切正常；担心/着急=守护有事件；睡=熄屏前奏。
- 点 Avatar（任意状态）= 进入对话：「你想问什么？」——**这是不会手势的人的唯一兜底，永远有效**。
- 有未读守护事件时，Avatar 头顶出现一颗小灯点，点击后先播报事件再进对话。

## 2. 四个方向

| 手势 | 去哪 | 内容 | 为什么是它 |
|------|------|------|-----------|
| **下拉** | 换场景 | 场景环：车 / 家 / 对话，三选一；Avatar 同步换装（守护态/亲子态/助手态） | 换「脑子」是最高频的切换，下拉手势行程最长、最不容易误触 |
| **上滑** | 当前场景的功能 | 该场景 2-3 个动作（见 §4），**不滚动、不超一屏** | 功能跟着场景走，圆屏上不出现「全部功能」这种东西 |
| **左滑** | 设置 | 音量/亮度/熄屏保持联网/演示模式/关于——五项封顶 | 低频但必须直达，不该藏在对话里 |
| **右滑** | 氛围屏 | 时钟 或 相册轮播（用户在设置里选一个作默认） | 屏的大部分时间属于「没人操作」状态，右滑是往「纯粹好看」里退，不是往功能里进 |

方向语义的直觉校验：下=打开更多世界（换场景）、上=掀开当前世界（看功能）、左=去不常去的地方（设置）、右=回到无事发生（氛围）。

### 2.1 状态互斥规则

- **SOS 布防/待发/已发期间**：四个手势全部冻结，屏上只有 SOS 进度。和手机侧 `card_next` 的拒绝逻辑同一族——呼救进行中不许被导航手势带跑。
- **对话进行中**：上下滑保留（可以边聊边切场景/看功能），左右滑忽略，避免聊到一半莫名进了时钟。
- **熄屏**：所有手势无效，POWER 键或下行 wake 唯一有效（沿用现有固件行为）。

## 3. 下拉·场景环

- 三个场景，横向卡片式呈现，Avatar 预览形象在每张卡上。当前场景居中，左右各露出相邻场景一个边。
- 松手即选定，Avatar 播一段 0.5s 的换装动画（不是换页面，是**同一张脸换了装扮**——强调「还是它」）。
- 不做「更多场景」入口。三域（车/家/对话）就是产品边界，圆屏上不假装还有第四个。

## 4. 上滑·场景功能层

每个场景固定 2-3 个动作，大按钮（≥72dp 高），一屏放下，**不允许滚动**：

- **车（守护态）**：看车在哪 / 下次过境 / 围栏开关
- **家（亲子态）**：讲个故事 / 看成长记录 / 管额度
- **对话（助手态）**：免提对话 / 静音

上滑层和手机端同名功能读写同一份状态，圆屏上改了围栏开关，手机上的卡片下一拍跟着变——不允许两边各说各话。

## 5. 右滑·氛围层

- 两种氛围：**时钟**（大数字 + 日期 + 下一场过境一行小字）或 **相册**（全屏轮播，家人照片从手机端推送）。
- 默认氛围在左滑设置里选；右滑进入后，再右滑在两种氛围间切换，点屏幕回 Avatar。
- 氛围层里守护事件**仍然要打断**：SOS/围栏事件一到，无论在哪张照片上，Avatar 直接顶出来变脸播报。氛围是退隐，不是失联。

## 6. 落地顺序（每步独立可验收）

1. **P0 — Avatar 常驻 + 点击对话**。改动最小、价值最大；现有 PixelAvatar/Muse 数据可直接用。
2. **P1 — 下拉场景环 + 换装**。三态形象先从现有 7 情绪里映射，不必新画。
3. **P1 — 左滑设置**。把屏上现有的设置页挂到这个手势下即可。
4. **P2 — 右滑氛围层**。时钟先做（纯本地），相册要手机端推图通道，随后。
5. **P2 — 上滑功能层**。等手机端 ViewModel 状态归属清理（任务 #8）完成后再接，避免两边状态打架。

## 7. 给固件的边界

- 四方向手势在 LVGL 侧识别（indev 的 swipe 判定），下行协议**不加新帧**：场景切换走已有的 `page_report`（通知语义不变），功能动作走已有 command，Clock/Photo 两页在 `state.ui.page` 七页枚举里扩两个页名（加性修订，老手机忽略）。
- Avatar 换装动画是屏侧资产（按场景切 sprite/调色），手机不推图。
